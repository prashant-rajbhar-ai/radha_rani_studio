# Radha Rani Studio

A wedding photography and videography business website built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## Project Structure

Radha-Rani-Studio
├── frontend  -> Static frontend files
├── backend   -> Backend API and database logic

## Frontend Technologies

- HTML5
- CSS3
- JavaScript

## Backend Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- Wedding photography portfolio
- Client gallery
- Booking system
- Payment integration
- Responsive design

## Hosting

- Frontend hosted on Netlify
- Source code managed using GitHub
